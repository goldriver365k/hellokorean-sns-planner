# HelloKorean SNS Planner

HelloKorean(https://hellokorean.site) 30일 글로벌 SNS 홍보 플래너.

## STEP 1 (완료)

- Vite + React 최소 프로젝트
- 4개 기본 화면: 대시보드 / 30일 계획 / 오늘의 홍보 / 설정
- 상단 Navigation
- LocalStorage 기반 데이터 저장 (서버/DB 없음)
- 반응형(PC/모바일) 기본 레이아웃

비용 최소화를 위해 AI API, Firebase/Supabase, 회원가입/로그인, SNS API 연동, 자동 게시 기능은 포함하지 않았습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 안내된 주소(기본 http://localhost:5173)로 접속합니다.

## 빌드

```bash
npm run build
npm run preview
```
